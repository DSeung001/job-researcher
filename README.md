# Job Researcher

잡코리아·원티드의 개발 공고를 모으고, 로컬에서 회사별로 검토하는 개인용 도구입니다. DB 서버와 LLM API는 필요하지 않습니다.

## 시작

Node.js 24 이상과 Git이 필요합니다.

```sh
npm ci
npx playwright install chromium
npm run dev
```

브라우저에서 http://127.0.0.1:4317 을 엽니다. 설정에서 출발역을 최대 2개 입력합니다. 해당 정보는 `.local/state.json`에만 보관됩니다.

```sh
npm run collect
npm run check
```

수집기를 처음 점검할 때는 `npx tsx src/collect.ts --max-pages 2 --max-details 3`으로 제한할 수 있습니다. 제한 실행은 의도적으로 불완전 수집으로 표시되고 종료 코드 1을 반환합니다. 전체 수집이 성공했다는 의미가 아닙니다.

## 사용

- 회사 스킵은 현재·미래 공고를 숨깁니다. 수집은 계속되며 스킵한 회사 탭에서 복원합니다.
- 관심 회사와 지원 완료는 독립 플래그입니다. 신규·수정은 마지막 ‘여기까지 확인’ 시각과 비교합니다.
- 같은 회사 연결은 다른 사이트나 이름으로 등록된 회사를 목록에서 선택합니다. 이름만 같은 회사는 자동 병합하지 않습니다.
- 통근은 지도에서 직접 확인 후 분 단위로 기록합니다. 두 출발역 중 더 짧은 시간을 사용하고 40분 이내에는 가점을 줍니다. 위치 미확인은 추천에서 제외하지 않습니다.
- 공고 데이터 갱신은 `git pull --ff-only`로 공개 데이터를 가져옵니다. Git 연결이 필요하며 로컬 수정 충돌은 자동 덮어쓰지 않습니다.
- 개인 상태 백업에는 출발역과 선택 기록이 포함되므로 공개 저장소에 넣지 마세요. 복원은 현재 상태를 교체합니다.

## 저장과 추천

`data/`에는 공고, `reports/`에는 수집 현황만 저장합니다. 개인 상태·설정은 Git에서 제외한 `.local/`에 저장합니다. 공고 상태는 `open / closed / unknown`, 개인 선택은 `isSkipped / isInterested / isApplied`입니다.

추천은 직무(40), 기술(최대 30), 경력 범위(15), 선호 도메인(8), 트래픽 근거(5), 통근(2) 순으로 가점을 합산합니다. 경력과 기술이 일부 일치하지 않아도 조회할 수 있습니다. 점수는 채용 합격 확률이 아닙니다.

GitHub Actions는 매일 한국시간 09:17·18:17과 수동 실행을 지원합니다. 예약 실행은 지연될 수 있고 공개 저장소의 장기 비활동 시 비활성화될 수 있습니다. 실행 실패·미완료는 Actions와 화면에서 확인합니다.

수집은 사이트 구조와 접근 정책에 영향을 받습니다. 본문이 이미지이면 텍스트 추출이 제한됩니다. 원티드는 브라우저 스크롤 정체를 종료 신호로 사용하므로 사이트 전체의 무누락을 보증하지 않습니다. 요청 차단을 우회하지 않습니다. 대량 수집 전 각 사이트의 이용 조건과 robots 정책을 확인하세요.

현재 실측: 잡코리아는 로컬·GitHub Actions에서 제한 수집과 자동 저장을 검증했습니다. 원티드 상세 HTML 추출은 가능하지만 목록은 로컬 자동화 브라우저와 GitHub Actions 모두 HTTP 403으로 차단됩니다. 따라서 원티드 신규 공고 자동 발견은 현재 동작하지 않으며, 양쪽 사이트의 완전 수집은 아직 검증되지 않았습니다. 수집 실패는 기존 데이터를 보존하고 불완전 상태로 표시합니다.

오래 확인하지 않은 공고부터 갱신하고 25건마다 중간 저장합니다. 명시적으로 마감되지 않은 기존 공고도 다시 확인합니다. 수집 프로세스가 강제 종료되어 잠금 파일이 남았다면 실제 수집 프로세스가 없는지 확인한 뒤 `.local/collect.lock`만 삭제합니다.

## 공개 전 점검

`npm run privacy`는 허용 경로, 주요 자격증명 패턴, 수집 데이터에 섞인 이메일·개인 상태를 검사합니다. 패턴 검사는 완전한 개인정보 탐지기가 아니므로 최초 공개 시 `git diff --cached`도 확인하세요. 개인정보가 한 번 커밋되면 `.gitignore`만으로 이력에서 사라지지 않습니다.

공개 프로필은 `config/profile.public.json`만 사용하며 개인 문서를 읽지 않습니다. 자동 커밋은 지정된 데이터 파일만 추가합니다. 로컬 API는 loopback에 바인딩하고 외부 Origin 쓰기 요청을 거절합니다.

디자인은 `docs/design.md`를 따릅니다. 모바일 원격 접속과 자동 교통 API는 첫 버전에 포함하지 않습니다.

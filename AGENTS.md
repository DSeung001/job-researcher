# Project rules

- Never commit `.local/`, credentials, personal contact details, commute origins, or private review state.
- Public profile fields must be explicitly selected; do not import private source documents.
- Preserve existing data on partial collection failure. Missing listings do not prove closure.
- Keep UI simple and follow `docs/design.md` for shared colors, spacing and controls.
- Run `npm run check` before committing. Only public data paths may be committed by polling automation.

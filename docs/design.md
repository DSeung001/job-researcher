# 화면 디자인 규칙

외부 참고: [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design).

개인 채용 목록을 빠르게 읽고 선택하는 데 집중한다. 장식용 이미지·그라데이션·자동 애니메이션은 사용하지 않는다.

- 바탕 `#f7f9fb`, 표면 `#ffffff`, 본문 `#182b3a`, 보조 `#536778`, 강조 `#2459a9`, 구분선 `#dce3ea`.
- 한국어 시스템 글꼴을 사용해 외부 폰트 요청을 만들지 않는다. 본문 16px, 제목 30px, 조작 요소 14px 이상.
- 왼쪽 정렬, 최대 너비 1120px, 8px 기반 간격. 회사 단위로 묶고 내부 공고는 구분선으로 나눈다.
- 버튼은 동일한 이름과 모양을 유지한다. 수집만 주 강조 버튼으로 둔다.
- 키보드 포커스·오류·빈 목록 안내를 제공하고 작은 화면에서는 세로로 재배치한다.
